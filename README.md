## 🌐 English Version

A modification for **Minecraft 1.20.1** based on the **Fabric** loader.

### 🌟 Description
Dreamland is a land of dreams and memories. It is a mysterious meta-space consisting of seven distinct layers. The player must venture through every single layer before they can escape.

### 🛠 Requirements & Installation
The following are required for the mod to work:
* **Minecraft 1.20.1**
* **Fabric Loader**
* **Fabric API**

#### Instructions:
1. Download and install **Fabric Loader**.
2. Place the downloaded `.jar` mod file and **Fabric API** into your `.minecraft/mods` folder.
3. Launch the game using the **Fabric** profile.

If you encounter any issues or bugs, please create an issue in the **Issues** tab of this repository.

## 🇷🇺 Русская Версия

Модификация для **Minecraft 1.20.1** на базе загрузчика **Fabric**.

### 🌟 Описание
Dreamland — страна снов и воспоминаний. Это загадочное мета-пространство, в котором есть семь слоёв. Игроку предстоит пройти каждый слой, прежде чем выбраться.

### 🛠️ Требования и Установка
Для работы мода необходимы:
* **Minecraft 1.20.1**
* **Fabric Loader**
* **Fabric API**

#### Инструкция:
1. Скачайте и установите **Fabric Loader**.
2. Поместите скачанный `.jar` файл мода и Fabric API в папку `.minecraft/mods`.
3. Запустите игру через профиль Fabric.
